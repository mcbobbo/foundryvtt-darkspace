# DarkSpace for Foundry VTT

An unofficial, complete sci-fi system module for playing **DarkSpace** (by DMing the World Press) built on the **Shadowdark RPG** system for Foundry Virtual Tabletop.

Originally created by [PrototypeESBU](https://github.com/PrototypeESBU/foundryvtt-darkspace), advanced and maintained by [mcbobbo](https://github.com/mcbobbo/foundryvtt-darkspace).

---

## Features

- **Actor Types**: Spacers and Starships with customized sheets, dynamic slot calculation, armor/shield handling, and cargo tracking.
- **Character Generator**: In-app wizard to generate Level 0 and Level 1 Spacers with citizen gear, species traits, archetype abilities, and random name tables.
- **Ship Generator**: Starship builder to design and purchase starships within class slot limits and credit budgets.
- **15 Compendiums**:
  - **Archetypes**: Charming, Clever, Machine-Based, Quick, Strong, Tough, Wise.
  - **Species**: Human, Alien, Android, Power Armor with species trait tables.
  - **Backgrounds**: 20 Spacer backgrounds.
  - **Gear & Cyberware**: Full cyberware catalog, survival gear, tech items, datapads, and comms.
  - **Languages**: 12 Sci-Fi languages.
  - **Stock Ships**: 30 pre-configured starships across all 6 classes (Explorers, Fighters, Freighters, Gunships, Research Vessels, Yachts).
  - **Ship Components & Armor**: Sublight/FTL drives, sensor suites, shield generators, and hull plating.
  - **Talents & Traits**: Personal talents, triad psionic powers, and starship combat traits.
  - **Weapons**: Personal firearms, vibroblades, grenades, and starship weapon batteries.
  - **NPCs**: 119 rich denizens with attacks and features ready to drop onto the canvas.
  - **Roll Tables**: 52 GM and solo sandbox tables (Astrogation Mishaps, Hazards, Job Generator, Salvage 0-10+, Cantinas, Planets, and SoloDark Oracles).
  - **Macros**: 10 utility macros for character generation, ship combat, astrogation, and sandbox tables.

## Installation

### Manifest URL (In Foundry VTT)
1. In the Foundry VTT Setup menu, navigate to **Add-on Modules** &rarr; **Install Module**.
2. Paste the following Manifest URL into the field at the bottom:
   ```
   https://github.com/mcbobbo/foundryvtt-darkspace/releases/latest/download/module.json
   ```
3. Click **Install**.

### Manual Installation
1. Download `darkspace.zip` from the [Latest Release](https://github.com/mcbobbo/foundryvtt-darkspace/releases/latest).
2. Extract the archive into your Foundry user data directory:
   `<FoundryUserData>/Data/modules/` (creating a folder named `darkspace`).
3. Restart Foundry VTT.
